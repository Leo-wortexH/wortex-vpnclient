## Почему Wortex?

### Ядро Xcore и singbox (Performance)
Собственная модификация ядра для максимальной производительности:
> **Zero-Copy TUN:** Клиент в реальном времени подбирает идеальный размер пакета под конкретную сеть (LTE/Wi-Fi).
>
> **Multi-Path:** Умное переключение между Wi-Fi и LTE без разрыва активных сессий а также работа вместе.
>
> **Battery Saver:** Оптимизированный JNI-мост снижает нагрузку на процессор на 30%.

### 🛡 Приватность и DPI
*  **Chaos Mode:** Уникальный алгоритм рандомизации пакетов (Jitter/Size) для защиты от ML-анализаторов трафика.
*  **VLESS Reality:** Лучший протокол для маскировки под обычные сайты (Google/Microsoft).

### 🗺 Визуальный контроль
* **Интерактивная карта:** Выбор сервера одним касанием по региону.
* **Live Ping:** Цветовая индикация задержки прямо на карте.

### ⚡ Smart Routing
* **Split Tunneling:** Банковские приложения и госуслуги работают напрямую, остальное — через шифрованный туннель.
* **App Filter:** Полный ручной контроль списка приложений.
