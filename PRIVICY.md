  ## 2. Какие данные обрабатываются

  Приложение может обрабатывать следующие категории данных:

  1. Технические данные VPN-соединения:
  - выбранный сервер
  - статус подключения
  - технические параметры сети (например, DNS, MTU, тип сети Wi‑Fi/мобильная)

  2. Данные конфигурации, добавленные пользователем:
  - ссылки подписок и параметры подключения
  - пользовательские настройки маршрутизации и интерфейса

  3. Диагностические данные:
  - логи ошибок и технические события запуска/остановки сервиса

  4. Данные устройства в минимальном объеме:
  - версия ОС
  - техническая информация, необходимая для работы VPN

  ## 3. Для каких целей используются данные

  Данные используются только для:

  1. Предоставления VPN-функциональности
  2. Настройки маршрутизации трафика и подключения
  3. Диагностики ошибок, поддержки и повышения стабильности
  4. Защиты сервиса от злоупотреблений и сбоев

  ## 4. Передача данных третьим лицам

  Мы не продаем и не передаем персональные данные пользователей третьим лицам.

  Данные, необходимые для работы VPN-подключения, обрабатываются только в технических целях обеспечения соединения и работы приложения.

  ## 5. Хранение данных

  1. Настройки и конфигурация обычно хранятся локально на устройстве пользователя
  2. Диагностические данные хранятся ограниченное время, необходимое для устранения сбоев
  3. После удаления приложения локальные данные удаляются системой Android, кроме случаев, когда они сохранены в резервных копиях устройства

  ## 6. Безопасность

  Мы применяем разумные технические и организационные меры безопасности для защиты данных, включая ограничение доступа и защиту каналов передачи данных.

  При этом ни один способ хранения или передачи данных через интернет не может гарантировать абсолютную безопасность.

  ## 7. Аудитория приложения

  Приложение не предназначено специально для детской аудитории.
  Мы не собираем персональные данные пользователей, включая детей, в маркетинговых целях.
